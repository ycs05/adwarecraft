# Adwarecraft

A small, client-side Fabric mod for Minecraft Java Edition 1.20.1, satirising apps that force ads into every spare moment.

Every three minutes of gameplay, a mock sponsored panel appears for up to 12 seconds. It rotates through deliberately pointless promotions, then closes by itself. Press **X** to dismiss it immediately. It never pauses the game, blocks controls, or connects to an ad service.

## Build

- Java 17
- Gradle 8.6 or newer

Run `gradle build`; the mod jar will be in `build/libs/`.

For development, import this project as a Gradle project and run the generated Minecraft client configuration.
